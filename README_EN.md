## 🎯 Mission Briefing

**"The Solitude Protocol"** is a 31-day extreme engineering experiment.  
I will enter complete social isolation, driven by the trinity of **Philosophy × Engineering × Art**, aiming to complete three runnable, measurable, and reproducible system-level constructs to explore the limits of focus and creativity.

1.  ⚙️ **C10K-capable HTTP Server** (`epoll` + memory pool + zero-copy I/O)
2.  🧵 **Thread-cached `malloc` Implementation** (1.5x faster than glibc)
3.  💻 **Bootable x86 Kernel to Shell** (running `fork` & `exec` in `QEMU`)

## ⏱️ Execution Protocol

1.  **Operation Hours**: Daily 09:00 – 23:00.
2.  **Log Archive**: Before **23:30** each day, record progress, key commits, performance metrics, and reflections in `LOG.md`. Quality over quantity.
3.  **Core Doctrine**: All code must be hand-written. Consulting `man` pages and documentation is permitted, but copying AI-generated code is strictly forbidden.
4.  **Circuit Breaker**: Each missed log entry results in a one-day project suspension with no makeup time.
5.  **Final Delivery**: Upon protocol completion, conduct public performance demonstration and publish flame graph analysis with paper-grade technical report.
